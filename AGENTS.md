# AGENTS.md

Windows-only Qt Widgets (C++17) app: a Task-Manager-style system monitor ("克铖操作控制台") with an embedded AI chat panel. Built and run in Qt Creator; no CI, no tests, no linter.

## Build & run

- Requires Qt 6.11.1 MinGW 64-bit (kit `qt.qt6.6111.win64_mingw_kit`). Build in Qt Creator, or manually:
  `cmake -S . -B build -G "MinGW Makefiles" -DCMAKE_PREFIX_PATH=<Qt prefix> -DCMAKE_BUILD_TYPE=Debug && cmake --build build`
- Output binary: `build/Desktop_Qt_6_11_1_MinGW_64_bit_Debug/KCSystemConsole-demo1-ui.exe`.
- **Third-party LLMQore dependency** (chat/AI): headers in `include/LLMQore/`, prebuilt `libs/libLLMQore.dll` + `libs/libLLMQore.dll.a` import lib. CMake links it directly (`CMakeLists.txt:64`) plus `Qt6::Network`/`Qt6::Concurrent`, and adds `include/` + source root as include dirs.
  - **Gotcha**: `include/` and `libs/` are currently **untracked in git** (and `.gitignore` ignores `*.dll`/`*.exe`), so a fresh clone will not build until these are supplied. The `libs/` Qt6*/`libgcc`/`libstdc++`/`dxcompiler` DLLs are runtime deployment copies, not build inputs.
- **Windows-only**: `processinfocollector.cpp` uses the Win32 API directly (`psapi`, `iphlpapi`, `tlhelp32`, `winsock2`); `mainwindow.cpp` also calls `GlobalMemoryStatusEx`. Won't build on Linux/macOS. CMake links `iphlpapi psapi`.
- CMake enables `AUTOUIC/AUTOMOC/AUTORCC`; Qt5 fallback branch exists but is untested — target Qt6.

## Architecture

- Entrypoint `main.cpp`: applies `:/styles/global.qss` and loads `:/i18n/KCSystemConsole-demo1-ui_<locale>` translations.
- Process collection runs on a dedicated `QThread` (`m_processThread`), driven by a `QTimer` (5 s interval, `initProcessPage`). `ProcessInfoCollector::doCollect()` → `collect()` → emits `collected(QList<ProcessInfo>)`, handled by `MainWindow::onProcessCollected`. CPU/disk rates are diffed against `m_prevSamples`; memory is "private working set" via `QueryWorkingSet`; network connection counts come from a prebuilt PID map (`buildNetworkMap`).
- Left menu (进程 / AI / 设置) switches `ui->mainContentStackedWidget` pages; the AI page embeds a `ChatWindow` widget (`aiChatMainWidget` in `mainwindow.ui`).
- `ChatWindow` (`ChatWindow.cpp`) wraps `LLMQore::OpenAIClient` (DeepSeek-compatible). It reads env vars: `DEEPSEEK_API_KEY` (required), `MY_CHAT_BASE_URL` (default `https://api.deepseek.com/v1`), `MY_CHAT_MODEL` (default `deepseek-chat`). Registers `ExecuteCommandTool` on the client's tool set.
- `ExecuteCommandTool.hpp` (`execute_command` tool) runs a **whitelist** of shell commands (`ls`/`dir`/`cat`/`grep`/`mkdir`/`rm`/…) in the project directory via `cmd.exe /c`; output is truncated to 64 KB.

## Conventions / gotchas

- `NumericTableItem.h` (header-only) subclasses `QTableWidgetItem` with a `sortKey` for numeric column sorting; `onProcessCollected` disables sorting during repopulation to avoid blank rows.
- `TwoRowHeaderView` is a custom `QHeaderView` that paints two-row headers.
- Styles in `styles/global.qss` (`QSSResources.qrc` → `:/styles/global.qss`); icons in `images/` via `imageResources.qrc`. UI layout is `mainwindow.ui`; process table is built in `mainwindow.cpp`.
- Translation source `KCSystemConsole-demo1-ui_zh_CN.ts`; `.qm` generated by `qt_create_translation` into `:/i18n/` during the CMake build (Qt Linguist).
- Repo comments and `README.md` are in Chinese.
- Adding a new source/header requires updating `PROJECT_SOURCES` in `CMakeLists.txt` (no globbing).
